# 点击后的新文档就绪契约

历史任务 714 的原执行结果保留为失败：14 个动作执行完成，投票落库，但页面脚本尚未绑定事件时点击触发原生表单，未满足评分要求的 AJAX 路径。相同延迟脚本场景在 Chromium、旧 Moli 和当前布局版本均复现。

修正仅位于独立的 browser-eval 执行器副本，不属于 Moli 功能补丁。DOM 点击和既有 500 ms 观察窗口保持；窗口内观察到主文档导航后，等待该导航的响应、文档提交及 DOMContentLoaded。普通点击、hash 导航不额外等待文档事件；导航失败与超时向上传播。没有任务号、站点、URL 或选择器特例，动作、评分、数据集和 CowAgent 保持原字节。

| 验证 | 原执行器 | 修正执行器 |
|---|---|---|
| 相同 14 个导航契约场景 | 5 通过、9 失败 | 14 通过 |
| 导航场景加既有回归测试 | 未作为整体重跑 | 46 通过 |
| 真实 Chromium + Playwright，7 场景 | 2 通过、5 失败 | 7 通过 |
| 当前布局二进制 + Playwright，7 场景 | 2 通过、5 失败 | 7 通过 |

真实浏览器场景覆盖慢脚本、慢响应头、同 URL 重载、重定向、普通点击、hash 导航和真实连接中断。判断依据为服务端收到的请求、实际脚本执行状态、同文档副作用和错误返回；浏览器事件未被模拟。测试调用原函数的完整 AST 定义，服务包装只提供真实 Playwright Page，因此不替代完整任务验收。

此契约不承诺 DOMContentLoaded 后任意异步应用初始化完成，也不覆盖观察窗口之后才发起的导航。修正合同下的任务结果必须单独标识；不能覆盖或改分原冻结执行器下的失败。
